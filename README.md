# 🐍 Python Quiz App

A simple and interactive **Quiz Application built with Python**.
The application asks users multiple-choice questions, checks their answers, and calculates the final score.

## ✨ Features

* 📝 Multiple-choice quiz questions
* ✅ Automatic answer checking
* 📊 Automatic score calculation
* 🎯 Final score display
* 💻 Simple and beginner-friendly Python project

## 🛠️ Technologies Used

* **Python 3**

## 📂 Project Structure

```text
Python-Quiz/

```

## 🚀 How to Run

1. Clone this repository:

```bash
git clone https://github.com/your-username/Python-Quiz.git
```

2. Open the project folder:

```bash
cd Python-Quiz
```

3. Run the Python file:

```bash
python quiz.py
```

## 🎮 How It Works

1. The program displays a quiz question.
2. The user selects an answer.
3. The program checks whether the answer is correct.
4. The score is updated automatically.
5. At the end, the final score is displayed.
